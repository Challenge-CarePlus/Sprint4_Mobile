# Trilha de fortalecimento orofacial (idosos)

Exercícios (ids em `ECOA_mobile/data/exercises.ts`):

1. `elderly-jaw-open-close` — Abertura e fechamento de boca
2. `elderly-pucker-hold` — Bico labial sustentado
3. `elderly-smile-hold` — Sorriso sustentado
4. `elderly-tongue-elevation` — Elevação de língua ao palato
5. `elderly-effortful-swallow` — Deglutição em esforço

Dois exercícios (4 e 5) têm nota de enquadramento diferente dos outros — o movimento neles
é mais difícil de ver de fora (língua quase escondida; esforço aparece mais no pescoço que na
boca).
